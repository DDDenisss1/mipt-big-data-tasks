##  Стек технологий

- **Apache Hadoop 2.6.0** (Cloudera CDH 5.11.2) на кластере МФТИ
- **Hadoop Streaming** (Python 3.4.3)
- **MapReduce** (двухпроходный алгоритм)
- **YARN** (управление ресурсами кластера)
- **Bash** (скрипт запуска `run.sh`)

## 💡 Архитектура решения

Использован **двухпроходный MapReduce** с тегированием слов для решения задачи, требующей контекстного анализа (слово должно быть Proper И никогда не встречаться в lowercase).

### 🔹 Проход 1: Тегирование и фильтрация

**mapper1.py** — парсинг и тегирование:
- Читает строки Википедии из `stdin` (формат: `id статьи <TAB> текст`)
- Извлекает слова через регулярное выражение `[a-zA-Z]+` (очистка от пунктуации)
- Фильтрует слова длиной **от 6 до 9 символов**
- Присваивает тег каждому слову:
  - `P` (Proper) — если слово начинается с заглавной, остальные маленькие → эмитит `word.lower() \t P \t 1`
  - `L` (Lowercase) — если слово полностью в нижнем регистре → эмитит `word.lower() \t L \t 1`

**reducer1.py** — агрегация и фильтрация:
- Группирует записи по слову (ключ сортировки Hadoop)
- Накопляет `proper_count` (сумма по тегу `P`)
- Устанавливает флаг `has_lowercase = True`, если встретился тег `L`
- **Фильтрует на выходе**: эмитит слово только если `proper_count > 0` И `not has_lowercase`
- Таким образом, слова, встречавшиеся в lowercase, полностью исключаются

### 🔹 Проход 2: Сортировка и топ-10

**mapper2.py** — identity mapper с валидацией:
- Читает отфильтрованные данные из первого прохода
- Переэмитирует `word \t count` с обработкой ошибок (`ValueError`, `IndexError`)
- Обеспечивает чистоту данных для финального редьюсера

**reducer2.py** — сортировка и выборка топ-10:
- Собирает все пары `(word, count)` в список `results`
- Сортирует по составному ключу: `(-count, word)` — сначала по убыванию частоты, при равенстве лексикографически
- Выводит **топ-10** записей

**Почему две джобы?**  
В рамках одного прохода MapReduce невозможно одновременно:
1. Найти слова, выглядящие как имена собственные (Capitalized)
2. Проверить, что они **никогда** не встречались в lowercase во всём корпусе

Первый проход собирает статистику и фильтрует, второй — сортирует и выбирает топ.
