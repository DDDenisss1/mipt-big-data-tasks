# MapReduce Task 1: Analysis of Proper Names in Wikipedia

*Учебная задача курса "Хранение и обработка больших объемов данных", ФПМИ МФТИ, 2026*

---

## 📋 Условие задачи

### Исходные данные
**Датасет:** Википедия (English Wikipedia)  
**Путь на кластере:** `/data/wiki/en_articles`  
**Семпл:** `/data/wiki/en_articles_part`  
**Формат:** Текст, в каждой строке: `идентификатор статьи <TAB> текст статьи`

### Задание
Посчитайте число вхождений **имён собственных длиной от 6 до 9 символов**.

**Критерии имени собственного:**
- Слово, начинающееся с **заглавной буквы**
- Последующие буквы — только **маленькие**
- Слово **ни разу не встретилось** в тексте с маленькой буквы

**Требования к обработке:**
1. Очищать слова от знаков пунктуации
2. Результат привести к **нижнему регистру**
3. Отсортировать по **убыванию числа вхождений**
4. При равенстве — **лексикографически**

### Формат вывода
- **В HDFS:** `имя количество`
- **На печать:** топ-10 имен

### Пример вывода
```
english 8358
states 7264
british 6829
...
```
