# MapReduce Task 2: Player Mortality Analysis in Game Sessions

*Учебная задача курса "Хранение и обработка больших объемов данных", ФПМИ МФТИ, 2026*

---

## 📋 Условие задачи

### Исходные данные
**Датасет:** Логи игрового сервера  
**Формат:** Текстовые строки с событиями игроков

### Типы событий в логах

| Событие | Описание |
|---------|----------|
| `UUID of player some_user is XXXX` | Начало сессии игрока |
| `some_user lost connection: Disconnected` | Конец сессии игрока |
| `some_user died` | Смерть игрока в сессии |

### Задание
Посчитайте **среднее количество смертей** (с точностью до сотых) за одну сессию по каждому пользователю. Также для каждого пользователя выведите **общее количество его сессий**.

### Требования к обработке
1. Сопоставить события начала и конца сессии с конкретным пользователем
2. Подсчитать число смертей в каждой сессии
3. Вычислить среднее количество смертей на сессию
4. Отсортировать результат по **среднему количеству смертей** (по убыванию)
5. При равенстве среднего — **лексикографически по никам**

### Формат вывода
```
some_user <tab> смертность <tab> число_сессий
```

### Пример вывода
```
avivzusim   0.24    15
lucky20    0    10
```
