# 🔥 NoSQL Databases: HBase/Cassandra Task

*Учебная задача курса "Хранение и обработка больших объемов данных", ФПМИ МФТИ, 2026*

---

## 📋 Условие задачи

### Общее описание

Необходимо разработать решение для анализа логов матчей игры PUBG с использованием **Apache HBase** или **Apache Cassandra**.

**Требования:**
- Данные преобразуются с помощью Hadoop или Spark
- Сохраняются в базу данных HBase/Cassandra в удобном для решения задачи виде
- Реализуются два компонента: writer и reader

### Архитектура решения

**1. Writer**
- Обрабатывает исходные данные из HDFS
- Преобразует и сохраняет результат в NoSQL базу
- Основная логика реализуется здесь (т.к. пишем реже, чем читаем)

**2. Reader**
- Клиент для отображения результата
- Консольное приложение
- Может содержать дополнительную логику преобразования данных

### Входные данные

**Датасет:** Логи матчей игры PUBG  
**Путь в HDFS:** `/data/hobod/pubg`

**Описание полей:**

| Поле | Описание |
|------|----------|
| `killed_by` | Тип оружия, которым был убит игрок |
| `killer_name` | Кто убил игрока |
| `killer_placement` | Рейтинг в матче (по кол-ву фрагов) |
| `killer_position_x`, `killer_position_y` | Где был убит игрок (координаты убийцы) |
| `map` | На какой карте проходит матч |
| `match_id` | Уникальный ID матча |
| `time` | Время от начала матча (в секундах) |
| `victim_name`, `victim_placement`, `victim_position_x`, `victim_position_y` | Аналогичные поля для убитого игрока |

### Задание

**Клиент должен уметь для каждого матча выводить TOP-10 типов оружия, с которых больше всего убивали игроков за определённый период времени.**

**Параметры:**
- Период времени задаётся парой `(start, end)` — время от начала матча в секундах
- Вывод: топ-10 оружий по количеству убийств

**Формат вывода:**
```
Match: <match_id>
Time period: [start, end]
TOP-10 weapons:
<weapon_type> - <kill_count> kills
<weapon_type> - <kill_count> kills
...
<weapon_type> - <kill_count> kills
```
