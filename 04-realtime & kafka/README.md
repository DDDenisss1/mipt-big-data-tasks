##  Условие задачи

### Задача 1: Эвристическая сегментация пользователей

**Сегмент** — это множество пользователей, определяющееся неким признаком.

Когда пользователь посещает web-сервис со своего устройства, это событие логируется на стороне web-сервиса в следующем формате: **user_id \<tab> user_agent**

Например:
```
f78366c2cbed009e1febc060b832dbe4	Mozilla/5.0 (Linux; Android 4.4.2; T1-701u Build/HuaweiMediaPad) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/62.0.3202.73 Safari/537.36
62af689829bd5def3d4ca35b10127bc5	Mozilla/5.0 (Windows NT 6.1; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/61.0.3163.100 Safari/537.36
```


#### Требования к сегментации

Необходимо разбить аудиторию (пользователей) в логах на следующие сегменты:

1. **Пользователи, которые работают в интернете из-под iPhone**
2. **Пользователи, которые используют Firefox браузер**
3. **Пользователи, которые используют Windows**

**Важно:**
- Не стоит волноваться, если какие-то пользователи не попадут ни в 1 из указанных сегментов (в реальной жизни часто попадаются данные, которые сложно классифицировать). Таких пользователей просто не включаем в выборку.
- Сегменты **могут пересекаться** (ведь возможен вариант, что пользователь использует Windows, на котором стоит Firefox).

#### Эвристики для выделения сегментов

| Сегмент | Эвристика |
|---------|-----------|
| `seg_iphone` | `parsed_ua['device']['family'] like '%iPhone%'` |
| `seg_firefox` | `parsed_ua['user_agent']['family'] like '%Firefox%'` |
| `seg_windows` | `parsed_ua['os']['family'] like '%Windows%'` |

#### Алгоритм подсчёта

Оцените количество уникальных пользователей в каждом сегменте, используя алгоритм **HyperLogLog** (поставьте `error_rate` равным 1%).

#### Формат вывода

В результате выведите сегменты и количества пользователей в следующем формате:
**segment_name \<space> count**


Отсортируйте результат по количеству пользователей в порядке убывания.

**Пример вывода:**
```
...
seg_firefox 4176
...
```

**Входные данные:** `/data/course4/uid_ua_100k_splitted_by_5k`

### Задача 5: Spark Streaming + Kafka

Добавить в код параметры для гибкого чтения данных из Kafka:

1. **Номер партиции**
   - Если указан — получаем данные только с неё
   - Если не указан — также, как и в задаче 5 (читаем из всех партиций)

2. **Начальный Offset и конечный Offset**
   - Если указаны оба — читаем данные только в указанных offset'ах
   - Если указан только конечный — читаем с начала и до указанного offset'а
   - Если указан только начальный — читаем от указанного offset'а до текущего времени
