## ℹ️ О репозитории

Этот репозиторий содержит **решения учебных задач** по работе с большими данными в рамках курса ФПМИ МФТИ. 

Здесь представлены:
- ✅ **MapReduce** задачи на Python с использованием Hadoop Streaming
- ✅ **Apache Hive** запросы для анализа данных о транзакциях ККТ
- ✅ Apache Spark задачи: BFS поиск кратчайшего пути (RDD + DataFrame API), извлечение коллокаций через NPMI
- ✅ Kafka & Real-time processing: эвристическая сегментация пользователей с HyperLogLog, Spark Streaming интеграция (Direct API), управление offset'ами и партициями
- 🚧 HBase/Cassandra (в разработке)

Каждое решение включает:
- Исходный код (SQL/Python скрипты)
- Подробную документацию с разбором архитектуры
- Объяснение принятых решений и альтернативных подходов
