##  Условие задачи

### Исходные данные

**Датасет:** Статьи Википедии (English Wikipedia)  
**Путь на кластере:** `/data/wiki/en_articles_part`  
**Формат данных:** `article ID <TAB> article text`

**Список стоп-слов:** `/data/wiki/stop_words_en-xpo6.txt`  
**Формат:** одно стоп-слово на строку

### Задание

Найти самые популярные коллокации в Википедии с использованием метрики **NPMI** (Normalized Pointwise Mutual Information).

**Коллокация** — это комбинация слов, которые часто встречаются вместе (например, "High school", "Roman Empire").

**Метрика NPMI:**

$$PMI(a,b) = \ln\left(\frac{P(a,b)}{P(a) \cdot P(b)}\right)$$

$$NPMI(a,b) = -\frac{PMI(a,b)}{\ln P(a,b)}$$

где:
- $P(a,b)$ — вероятность двух слов, идущих подряд
- $P(a)$ и $P(b)$ — вероятности слов $a$ и $b$ соответственно

**Вероятности вычисляются как:**
- P(a)=num_of_occurrences_of_word_"a" / num_of_occurrences_of_all_words
- P(ab)=num_of_occurrences_of_pair_"ab"‘ / num_of_occurrences_of_all_pairs

### Требования к обработке данных

1. **Очистка текста:** отбрасывать все символы, не являющиеся латинскими буквами: `text = re.sub("^\W+|\W+$", "", text)`
2. **Нормализация:** приводить все слова к нижнему регистру
3. **Удаление стоп-слов:** удалять все стоп-слова (даже внутри биграмм, т.к. "at evening" имеет ту же семантику что и "at the evening")
4. **Формирование биграмм:** объединять символом нижнего подчёркивания "_"
5. **Фильтрация:** работать только с теми биграммами, которые встретились **не реже 500 раз**
6. **Подсчёт статистики:** общее число слов и биграмм считать **до фильтрации**

### Формат вывода

Вывести на экран (в STDOUT) **TOP-39** самых популярных коллокаций, отсортированных по убыванию значения NPMI. **Само значение NPMI выводить не нужно.**

**Пример вывода:**
```
roman_empire
south_africa
```
